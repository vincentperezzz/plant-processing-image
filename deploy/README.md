# Plant Health kiosk

Names a farm crop (palay, sili, tomato, eggplant, lettuce), grades **healthy / mild / critical / dead**, and shows a short tip.

This zip is the GitHub release: Windows PC simulation **and** Raspberry Pi 4B kiosk. Same `models/best.pt` grader.

| Machine | What you get |
| --- | --- |
| **Windows PC** | 1024×600 window, USB webcam, MobileNet only (same diet as the Pi) |
| **Raspberry Pi** | Fullscreen 7 inch panel, CSI or USB camera, **offline** install |

Not in this pack: YOLO-World, CLIP, training photos, or the full git repo.

**Install:** [INSTALL.md](INSTALL.md)

Crops: palay, eggplant, lettuce, tomato, sili. Health: healthy, mild, critical, dead.
